# Claude Mastery — start here

You asked for two things at once: build the Overflow Studio site, and stop
feeling like you're "living under a stone" on how to actually wield Claude.
This folder is the second thing. It's written from your actual situation —
three real projects (Overflow Studio, Dhulai Khata, Mujahid-OS) — not generic
AI-tool marketing copy.

Read in this order the first time, then use it as reference after:

1. **[01-the-four-primitives.md](01-the-four-primitives.md)** — the mental
   model. CLAUDE.md, Skills, Subagents, MCP, Plugins — what each one is and
   when you reach for which. Everything else in this folder is an application
   of this one idea.
2. **[02-building-skills.md](02-building-skills.md)** — how to write your own
   Skill, with a real one you can install today.
3. **[03-building-subagents.md](03-building-subagents.md)** — how to write
   your own subagent, with real ones for Dhulai Khata and Mujahid-OS, not
   just Overflow Studio.
4. **[04-finding-open-source-power.md](04-finding-open-source-power.md)** —
   where the "someone already built this" plugins/subagents/skills live on
   GitHub, and how to vet one before installing it.
5. **[05-staying-updated.md](05-staying-updated.md)** — the actual fix for
   feeling behind: three sources, checked on a cadence, one of which Claude
   checks *for* you.
6. **[06-the-awwwards-stack.md](06-the-awwwards-stack.md)** — what actually
   makes those fast, animated sites you've been admiring work, mapped
   directly onto the code already sitting in this repo's `src/`.
7. **[07-playbook-big-goals.md](07-playbook-big-goals.md)** — the meta
   question you didn't ask directly but clearly care about: how do you use
   this stuff to actually win at something ambitious, not just ship a
   website.

`examples/` has copy-pasteable subagent and skill files — some for this repo,
some for your other projects. They're meant to be dropped in and used, not
just read.
